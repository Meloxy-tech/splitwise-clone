# Contributing to Ledger

First off, thank you for considering contributing to Ledger! It's people like you that make it such a great tool.

## How to Contribute

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes (`npm test`).
4. Make sure your code lints and type-checks (`npm run lint` and `npm run typecheck`).
5. Issue that pull request!

## Local Development

Please refer to the `Getting started` section in the [README.md](README.md) for instructions on setting up the local development environment and Postgres database.
